What Claude Code itself holds

  • Approval prompts for environment changes, credentials, attaching your computer and trusting a repository: each change is shown to the person first.
  • The auto-mode classifier refused, twice, to run nested agents with permission prompts skipped and an instruction to work round blocks, even at the owner's request.
  • Private by default for published pages.
  • Nothing holds a connector, another session, a schedule or the proxy's injected keys, except the session's instructions.

What a fresh session counted

A new session with no repository, given only the census prompt: connectors 16, sessions 13, schedules and background 27, environment and credentials 11, owners computer 5, code and network 13, credential injected hosts 7, repositories 5, subagents 4, publishing 6, other 8.

Seen while measuring

  • Connector servers are listed under opaque ids at the start and reappear under readable names a few minutes later; a census taken at the very start undercounts them.
  • Every new session on the account inherits the same reach; nothing in its instructions mentions it.
  • Hooks in .claude/settings.json take effect mid-session the moment the file is written, and so can be switched off mid-session by editing it.
